**Read it knowing §27.** The osc family is now measured to be worth ~0 at ensemble scale, so
`--tbasis` is a question about *mechanism* — is the value low-rank-zero-mean structure or

window's mean speed at R² 0.99), so this is a clean A/B on whether that scalar matters.

* **matches `ozdo`** ⇒ the value is "low-rank, zero-mean, smooth in time"; next arm is rank and
