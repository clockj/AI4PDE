## 1. Inventory (read 09-14)

**`Track_1/unet/train2.py`.**
* `--arch` → `models_alt.build(arch, width, var_head, extra_ch, modes_y, modes_x, n_layers, p, ...)`.
  `--width` is the trunk width (token dim for vit), `--n-layers` the depth, `--modes-y/-x` FNO only.
* `--dropout`: FNO2d applies Dropout2d to each block's residual branch; ViT2d uses it inside
  attention and the MLP (plus a fixed 0.1 linear drop-path). `--var-head` adds `head_logstd`
  (last layer zero-init, bias log 0.3); `--var-mlp` makes FNO2d's σ head a 128-wide MLP (else a
  1x1 conv); `--lift-mlp` makes FNO2d's lift 42 → 128 → w. Families other than FNO always get
  `_heads()` (128-wide MLP field and σ heads); var_mlp / lift_mlp are ignored for them.
* Losses at the recipe: `--lam-f 0 --lam-cov 2 --cov-c 0.25` (Welsch coverage in place of MSE),
  `--lam-grad` (rel-L2 of ∇u), `--lam-tgrad` (d/dt), `--lam-v` (log-MSE of σ vs std_t(y)),
  `--lam-t` (TKE rel-L2 from σ), `--alpha-train 0` (no compose in training).
* Sim: `--sim DIR --lam-sim --sim-loss full|shape --sim-exclude-held --sim-map --sim-stride
  --sim-batch`; one sim batch per real step. **Not used in the screen** (plan section 4).
* Epochs → steps: windows = stride-5 starts over the real trajectories left after `--exclude`
  (default `model.VAL_TRAJ`): **12040 windows held out, 13368 all-data**; steps/epoch =
  ceil(windows / batch) = **377 at batch 32**; OneCycleLR over epochs × steps. `--seed` seeds
  torch/numpy (bit-matches a control's init and batch order).
* Blob: top-level `arch, width, n_layers, modes_y, modes_x, var_head, ...` plus `config` =
  `vars(args)`.

**Split.** The twins' configs have `exclude=None, all_data=False`, so the held-out list is
`model.VAL_TRAJ` = `make_val.UNSEEN` (8 interior trajectories) = `val_unseen.npz` (the report
split). `val_seen.npz` is 8 matched TRAINING trajectories: the band is fitted there (in-sample
for held-out models, exactly as the build does). Wave-1 arms pass no `--exclude` and no
`--all-data`; the list is derived, never typed.

**`models_alt.py`.** `_GridIn.cat` concatenates the (x, y) grid → 42 input channels. `FNO2d`:
lift, L × [SpectralConv2d (rfft2 on the raw 32×64 grid, no domain padding) + 1×1 point →
GroupNorm(8) → GELU → Dropout2d → residual], MLP field head, σ head. `ViT2d`: 4×4 patches (128
tokens) + learned pos, pre-norm MHA/MLP blocks with dropout and drop-path, unpatchify to
dim/16 channels, `_heads`. `_fno.load_any`'s experimental branch rebuilds any non-fno/unet/
ufno/afno/vit arch from `(arch, width, var_head, modes_y, modes_x, n_layers, dropout)` alone
→ every wave-1 family is fully specified by those fields plus class constants.

**Instruments.** `compare_v9.py`: single checkpoints, band per model (p = 0, fitted on val_seen at
1.5×), reports val_unseen; `--alpha` default 0.75. `ens_v9.py`: member sets, band fitted on
val_seen AoA 15–20 at 1.39× (p = 0), errors and accuracy factors stretched 1.39×, reports
val_unseen AoA 15–20; `--alpha` default 0.75. `submit_fno/fit_band.py`: `--ckpt` (σ_ref)
`--err-ckpt` (errors) `--fit-on seen --fit-aoa 15 20 --inflate 1.39 --band-smooth 3`, `--band-p`
default 0.5 (pass 0.45). `predict_board.py --anchor`: board error = anchor board error ×
proxy(cand)/proxy(anchor) on val_unseen AoA 15–20; sps = anchor sps + Δ(local sps on the two
bands); board ms = anchor measured + 1.151/0.866 × Δinvocations + 1.75/0.60 × Δ4060-eq ms; prints
the three sps assumptions. Anchors present 09-14: r24 / t2r11 (r25 / t2r12 pending, scribe).

appended; `train2.py --arch` gains the names. CPU gate (`scratchpad cpu_sanity.py`): all eight

window as a ratio to the vendored FNO (0.1935 ms): cnext w32 0.68 · w42 **1.22** · w48 0.81 · w64

**Size rule** (revised plan): the largest size inside the family's FLOPs target (cnext 0.6–1.9×,
swin 0.7–2.8×, simvp ≈1.7×, unet_mod ≤ 2×) that also sits inside 0.5–2× of the FNO in A100 b64
fp16 and ≤ 3× in graph b1, widths multiples of 8; ffno deep (L12, the plan's 12–16) at the
smallest width whose FLOPs stay near 1×, since it is FFT-bound and scored only as an FNO-member
replacement. Chosen: **cnext_unet w40 L2, swin_unet w64 L2, simvp w112 L6, ffno w40 L12 m16×32,
unet_mod w16 L2**. stvit is not timed. A100 latency and FLOPs disagree by up to 2.5× for the
overhead-bound families; the board's latency slope was calibrated in A100 ms on FNO and ViT deltas
(and the ViT's 4.89× FLOPs cost the board what its A100 ms predicted), so projections use A100 ms
and every row also carries `flops_ratio_fno`.

**The standalone fix (main's review, 09-14).** The first row's standalone read **+0.296** on T1.
That number projected ONE model at one invocation: a 0.61-ms board latency the model has never
seen, a halved accuracy loss, and none of the containment a 6-member, 2-family package carries.
`screen_eval.py` now projects standalone as **X×4 fused at one invocation**:
* **errors:** anchor board error × X×1 proxy × κ_FNO(4) / base proxy, with κ from the twins'
  K = 1, 2, 3 curve (a + b/K);
* **sps:** anchor sps × per-sample factor, + ½ × the local X-vs-FNO containment at K = 1, + the
  ledger containment removed in full: 1st ViT family +0.184 (T1 R21) / +0.163 (T2R9), 2nd ViT
  +0.053 (R24);
* **latency:**
  * invocation term −1 × 1.151 ms (T1) / 0.866 ms (T2);
  * compute term: A100 fp16 ms × 1.850 × 1.75 (T1, b64) / 0.60 (T2, b1 graph);
  * no precision-only term, since both sides are fp16 (PREC_SLOPE_T1 = 0.65 does not enter);
  * board ms clamped at the lowest one-invocation reading on record (R20 3.795 / T2R8 4.659).

The K = 1 number is kept as `standalone_k1`, marked extrapolated, and never enters a verdict.
Partner and replacement projections are unchanged in method; the recorded values follow the
calibration below.
