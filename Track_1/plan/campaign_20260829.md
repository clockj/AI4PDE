## WP-1 FGN spec (implementation brief — see agent instructions for detail)

Smallest honest version, per plan_20260810: FiLM-from-noise on the FNO's GroupNorms
(z∈R^32 → per-layer Linear(32→2·width), zero-init so z or the maps at 0 reproduce the
baseline bit-for-bit), K=4 sample passes per step, **fair CRPS** per element in normalized
units on the sample fields, added to the untouched BASE losses (z=0 pass):
`loss = BASE(z=0) + lam_crps · CRPS(samples, y)`. Eval (`eval_fgn.py`): K_eval=8 fixed-seed
draws; σ candidates = head(z=0) / mean_k std_t(sample_k) / sqrt(mean_k var_t(sample_k));
report σ rel-L2 vs std_t(y), TKE and wfinal on the AoA proxy against the fresh baseline seeds.
**Screen: if no σ candidate beats the head's, stop the branch** — do not tune it into working.
Deployment (only if it wins): K draws = batch-axis expansion inside one invocation; fuse()
untouched; fixed RNG for determinism.

## FGN implementation notes (2026-08-29)

**Built** (CPU-verified, nothing trained): `models_alt.FNO2d(fgn_dim=)` adds
`film[i] = Linear(fgn_dim, 2*width, bias=False)`, zero-init, applied to the GroupNorm output
inside each block as `(1+dg)*n(s(h)+p(h)) + db`; `forward(prev, detach_var, z=None)`.
`train2.py` gains `--fgn K` / `--fgn-dim` / `--lam-crps`: the existing forward is the z=0 pass
and every existing loss is unchanged, then K extra forwards add
`lam_crps * fair_CRPS(samples, y)` in normalized units. Two new log columns, `crps` and `svar`
(= rel-L2 of `mean_k std_t(x_k)` against `std_t(y)`), appended after `spec`; existing columns
untouched. `fgn_dim` (0 when off) is stored in the blob and in `config`. `eval_fgn.py` is the
screen. **Not touched:** `_fno.py`, `submission.py`, `fit_band.py`, `runq.sh` — deployment waits
on the verdict.

**Verified, CPU, 23/23:** `forward(x)` == `forward(x, z=0)` == `forward(x, z=None)` at maxabsdiff
**0.0**, and equal to a `fgn_dim=0` model carrying the same weights — the centre of the sample
distribution *is* the baseline. Randomized film + z~N(0,I) moves the field (rel. spread 0.462)
and gradients reach `film[0]`. Fair CRPS at K=512, y=0, x~N(0,1): **0.23365 vs analytic 0.23369**;
unbiased at K=4 over 60 replicas (0.23391); 0 for a perfect forecast; = MAE for identical
samples. **At init the spread term is exactly 0**, so `crps` starts as the field MAE. Checkpoint
round-trip through `eval_fgn.load_alt` is bit-exact; a blob without `fgn_dim` still loads
`strict=True` (no `film.*` keys are created when `fgn_dim=0`). `eval_fgn`'s band scorer agrees
with the kit's `aggregate_sps` to **1.7e-8**. Pre-existing bug fixed on the way: `--chan-pow`'s
help had an unescaped `86%`, which made `train2.py --help` raise `TypeError`.

**Queue lines** (BASE from `runq.sh` supplies the rest; `--var-mlp --lift-mlp` per the R arms):

```

fno_fgn2.pth       --var-mlp --lift-mlp --fgn 4 --lam-crps 0.1     # only if fgn1 is not a clear fail
```

**Cost — read before scheduling.** A `--fgn 4` step is **4.6x** a baseline step (CPU, batch 8:
480 ms vs 104 ms; K+1 forwards, one backward through all of them). At an 8–15 min baseline arm
that is **35–70 min** for `fno_fgn1`, which is the whole of gate F's slack. `--fgn 2` is ~2.6x
and the fair estimator is still unbiased at K=2 (only noisier — its spread term is one pair);
drop to it, or cut `--epochs`, if the clock is tight.
